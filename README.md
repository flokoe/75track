# 75track

A simple, low-friction web app for tracking progress on the 75 Hard challenge (or any custom challenge variant).

## Features

- Custom challenge creation with configurable tasks
- One-tap daily task tracking
- Progress visualization with streak counter
- Calendar view for history
- Offline-first with local storage
- Mobile-friendly design

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Zustand (state management)
- Vite (build tool)

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
